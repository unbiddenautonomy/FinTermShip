# Design concepts (13 November 2026)

Four interactive mockups made by Claude to explore directions that change how the app works, not just its colours. Open `index.html` in a browser for the overview with each idea's bet and risk; each concept also has its own page. They are samples only and are not part of the app or the build.

- `term-lines.html`: the syllabus as a metro map. Built as the Lines mode.
- `call-it.html`: one claim per card, flick for true or false. Built as the Call It mode.
- `recall-exchange.html`: each term is a stock whose price is how well you remember it. Built as the Exchange mode.
- `interview-room.html`: the app as a chat with a desk head. Not chosen.

They load fonts from Google Fonts and nothing else. Screenshots of them are kept in the project's shared files, not here.
